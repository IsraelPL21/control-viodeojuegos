# ControlVideojuegos V29.22 — PWA

Esta versión agrega una carcasa PWA instalable para iPad/iPhone.

Archivos principales:
- index.html
- app.js
- manifest.webmanifest
- sw.js
- icons/

Importante:
La PWA permite instalar la interfaz como una aplicación, pero todavía usa el almacenamiento local del dispositivo.
La sincronización PC ↔ iPad con una base de datos compartida es una etapa posterior.

Para instalarla en iPad:
1. Publica esta carpeta en un sitio HTTPS.
2. Abre la dirección en Safari del iPad.
3. Usa Compartir → Añadir a pantalla de inicio.
